## GitHubCard.vue
``` markdown
<GitHubCard url="https://github.com/vuejs/core" />
```
参数 `url` 填入仓库地址，示例：
<GitHubCard url="https://github.com/vuejs/core" />

## GiteeCard.vue
``` markdown
<GiteeCard url="https://gitee.com/quchenghao/wechatmsg" />
```
参数 `url` 填入仓库地址，示例：
<GiteeCard url="https://gitee.com/quchenghao/wechatmsg" />

## NeteaseMusicCard.vue
``` markdown
<NeteaseMusicCard id="1363276989" />
```
参数 `id` 填入音乐ID，示例：
<NeteaseMusicCard id="1363276989" />

## WordCount.vue
1. **默认：自动识别当前一级分组**
``` markdown
<WordCount label="当前笔记字数：" />
```
示例：
<WordCount label="当前笔记字数：" />

2. **识别当前二级分组**
``` markdown
<WordCount :depth="2" label="当前二级分组字数：" />
```
示例：
<WordCount :depth="2" label="当前二级分组字数：" />

3. **手动指定某个分组**
``` markdown
<WordCount path="/notes/qian-ru-shi-kai-fa/" label="嵌入式开发 分组总字数：" />
```
示例：
<WordCount path="/notes/qian-ru-shi-kai-fa/" label="嵌入式开发 分组总字数：" />

4. **显示全站总字数**
``` markdown
<WordCount path="/" label="全站总字数：" />
```
示例：
<WordCount path="/" label="全站总字数：" />

## GroupDirectory.vue
- 自动识别当前 README 所在物理目录
- 自动读取同级 Markdown 的标题、摘要、日期、图标和字数
- 新增或删除 Markdown 后，开发环境或重新构建时自动更新
- 支持递归目录、名称/日期排序和手动指定目录

``` markdown
<GroupDirectory />
```
示例：
<GroupDirectory />

## GitHubReadme.vue
- 支持完整 GitHub URL 或 owner/repo
- 使用 GitHub 官方 HTML 媒体类型获取已渲染 README
- 包含骨架加载、错误重试、分支信息、仓库入口
- 超长内容默认折叠，可展开/收起
- 清理危险 HTML，并隔离远程 README 锚点，避免与页面标题冲突

``` markdown
<GitHubReadme url="https://github.com/DavidBlackCN/DB-Blog-Plume" />
```
示例：
<GitHubReadme url="https://github.com/DavidBlackCN/DB-Blog-Plume" />
