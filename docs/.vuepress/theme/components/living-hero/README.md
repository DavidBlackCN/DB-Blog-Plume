## 宿主行为

- 普通首屏延伸至 Plume 导航背后，导航使用主题色半透明遮罩与模糊，首屏内容避开导航高度。保留场景全部控制、真实本地时钟及原图构图；网站主题与场景时间独立。
- 社交图标使用博客原有真实链接。下滑提示和可刷新的一言位于首屏底部，下方继续展示站点介绍与导航。
- 沉浸保持同一画布实例，以固定首屏覆盖视口，保留时钟资料区；其余页面分支临时 inert，退出恢复焦点、滚动位置及原 inert 状态。
- 全屏仅请求首屏节点。H 只在首屏可见且没有编辑输入/操作外部弹层时响应；Esc 逐层关闭控件和沉浸。卸载时清理监听、锁定及全屏。
- 加载/降级提示避开个人资料区，避免重试按钮被覆盖。`data-status` 与错误提示的 `data-reason` 可用于排查，不把技术错误文本作为默认界面文案。
- 共用的站点运行时长改为挂载前稳定占位，修复原 About 区域构建时间与访问时间不同导致的水合警告。
