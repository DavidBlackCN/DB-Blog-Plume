LiteyukiBot v6 的长期维护分支，面向仍需使用 v6 插件、配置和多进程架构的部署。项目保持 Liteyuki v6 主进程与 NoneBot2 子进程的既有边界，并持续适配当前 Python、OneBot 与 NoneBot 生态。

> 这是 v6 LTS 维护线，不是当前正在开发中的 LiteyukiBot v7 升级包；请勿将 v7 的配置、命令或插件管理方式直接套用到本项目。
